# ITP2020 Gym Management System

Full-stack gym management system for FitCore Gym — ITP2020 Assignment 2 (Group Project).

## Tech Stack
- **Backend:** ASP.NET Core 8 Web API + EF Core + ASP.NET Identity
- **Database:** Microsoft SQL Server
- **Frontend:** React + React-Bootstrap

## Project Structure

- `backend/` — ASP.NET Core Web API
- `frontend/` — React + React-Bootstrap app
- `database/` — SQL scripts
- `docs/` — Documentation, ERD, Use Case

## Branches
- `main` — stable, demo-ready
- `develop` — integration branch
- `feature/*` — individual features
