# Frontend — React + React-Bootstrap

## Overview
React frontend for the Gym Management System.

## Tech Stack
- React
- React-Bootstrap
- Axios
- React Router

## Structure
- `src/components/` — Reusable components
- `src/context/` — React context (AuthContext)
- `src/pages/` — Full pages (Login)
- `src/services/` — API communication (api.js)
- `src/App.js` — Routes
- `src/index.js` — Entry with providers

## Setup
1. `npm install`
2. Make sure the .NET API runs on http://localhost:5049
3. `npm start`
4. Open http://localhost:3000
